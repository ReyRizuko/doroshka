Перенос из Spotify

Spotify не отдаёт сами песни: они защищены, и скачать их нельзя. Переносится список треков, а звук берётся из ваших файлов.

  1. Откройте exportify.net, войдите в Spotify и сохраните плейлист в CSV.
  2. Загрузите этот файл сюда. Подходит и Playlist1.json из запроса данных аккаунта Spotify.
  3. Добавьте свои песни кнопкой «Добавить песни». Совпадения найдутся по названию и исполнителю.

Настроить поиск YouTube (API key)

Ключ хранится локально на этом устройстве. После сохранения YouTube автоматически участвует в каждом общем поиске через YouTube Data API v3.

Для поиска добавьте API key. Можно также открыть поиск YouTube в браузере.
