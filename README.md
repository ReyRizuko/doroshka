# Дорожка

Музыкальный плеер для Android. Играет файлы с телефона и переносит плейлисты из Spotify
(CSV из exportify.net или JSON из данных аккаунта) с сопоставлением по названию и исполнителю.

## Как получить APK без установки чего-либо

1. Создайте на github.com пустой репозиторий (можно приватный).
2. Загрузите в него содержимое этой папки (Add file → Upload files). Папку `.github` тоже.
3. Откройте вкладку Actions, выберите «Сборка APK», нажмите Run workflow.
4. Через 5-8 минут откройте завершённый запуск и скачайте `dorozhka-apk`. Внутри `app-debug.apk`.
5. Перенесите APK на телефон, откройте его и разрешите установку из этого источника.

## Локальная сборка
Нужны Node 20+, JDK 21 и Android Studio:
npm install && npm run android && npx cap open android
