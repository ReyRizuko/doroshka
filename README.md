# Дорожка

Музыкальный плеер для Android: локальная медиатека, очередь воспроизведения, фоновый плеер и импорт плейлистов Spotify (CSV/JSON).

## Источники

- **Локальные файлы** — музыка с устройства, включая чтение тегов и обложек.
- **Spotify** — импорт списка треков из CSV/JSON. Spotify не передаёт аудиофайлы; для воспроизведения нужны локальные копии или другой легальный источник.
- **YouTube** — поиск через YouTube Data API v3 и воспроизведение видео во встроенном официальном YouTube-плеере. Нужен собственный API key.
- **Яндекс Музыка** — переход к официальному поиску Яндекс Музыки. Встроенный каталог/поток не подключается: для этого требуется поддерживаемый авторизованный API.
- **SoundCloud** — переход к официальному поиску SoundCloud.
- **Jamendo** — поиск и потоковое воспроизведение свободной музыки; нужен Client ID.
- **Internet Archive** — поиск аудиозаписей и потоковое воспроизведение доступных MP3.

### Настройка YouTube

1. Откройте Google Cloud Console: https://console.cloud.google.com/
2. Создайте проект и включите **YouTube Data API v3**.
3. Создайте API key в разделе Credentials.
4. В приложении откройте «Интернет» → «YouTube» → «Настроить поиск YouTube» и вставьте ключ.

Ключ сохраняется в localStorage на текущем устройстве. Ограничьте ключ в Google Cloud по API и, если возможно, по приложениям/доменам. У YouTube API есть квоты.

### Настройка Jamendo

1. Зарегистрируйтесь на https://devportal.jamendo.com/
2. Создайте приложение и скопируйте Client ID.
3. В разделе «Интернет» → «Jamendo / Archive» сохраните Client ID.

## Сборка APK через GitHub Actions

1. Откройте вкладку **Actions**.
2. Выберите workflow **Сборка APK**.
3. Нажмите **Run workflow** или дождитесь сборки после push/merge в основную ветку.
4. В завершённом запуске скачайте artifact `dorozhka-apk`. Внутри находится `app-debug.apk`.

## Локальная сборка

Нужны Node.js 20+, JDK 21 и Android SDK/Android Studio:

```sh
npm install
npm run android
npx cap open android
```
