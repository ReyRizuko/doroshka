# Дорожка

Музыкальный плеер для Android: локальная медиатека, очередь воспроизведения, фоновый плеер и импорт плейлистов Spotify (CSV/JSON).

## Источники

Вкладка **Интернет** объединяет поиск по музыкальным платформам:

| Источник | Возможности внутри приложения |
|---|---|
| Локальные файлы | Полное воспроизведение, очередь, фоновый режим, теги и обложки |
| YouTube | Поиск через YouTube Data API v3 и официальный встроенный видеоплеер; требуется собственный API key |
| Jamendo | Поиск и потоковое воспроизведение; нужен Client ID |
| Internet Archive | Поиск записей, выбор MP3 и потоковое воспроизведение |
| Spotify | Импорт плейлистов CSV/JSON; звук берётся из локальных файлов |
| Яндекс Музыка | Официальный поиск в сервисе |
| SoundCloud | Официальный поиск в сервисе |
| Apple Music | Официальный поиск в сервисе |
| Deezer | Официальный поиск в сервисе |
| Bandcamp | Официальный поиск в сервисе |
| VK Музыка | Официальный поиск в сервисе |

Внешние каталоги открываются на официальных страницах. Это не выдаётся за встроенное потоковое воспроизведение: доступ к нему зависит от API, авторизации и условий платформы.

### Настройка YouTube

1. Откройте Google Cloud Console: https://console.cloud.google.com/
2. Создайте проект и включите **YouTube Data API v3**.
3. Создайте API key в разделе Credentials.
4. В приложении откройте «Интернет» → «YouTube» → «Настроить поиск YouTube» и вставьте ключ.

Без ключа поиск открывается на официальном сайте YouTube. Ключ сохраняется в localStorage на текущем устройстве. Ограничьте ключ в Google Cloud по API и, если возможно, по приложениям/доменам. У YouTube API есть квоты.

### Настройка Jamendo

1. Зарегистрируйтесь на https://devportal.jamendo.com/
2. Создайте приложение и скопируйте Client ID.
3. В разделе «Интернет» → «Jamendo / Archive» сохраните Client ID.

## Сборка APK через GitHub Actions

1. Откройте вкладку **Actions**.
2. Выберите workflow **Build APK**.
3. Нажмите **Run workflow** или дождитесь сборки после push в основную или feature-ветку, либо при открытии Pull Request.
4. В завершённом запуске скачайте artifact `dorozhka-apk`. Внутри находится `app-debug.apk`.

Workflow автоматически размещает `index.html` и `prepare.js` в каталогах, которые ожидает Capacitor.

## Локальная сборка

Нужны Node.js 20+, JDK 21 и Android SDK/Android Studio:

```sh
npm install
npm run android
npx cap open android
```
